# 最近股票搜索记录设计

## 记录范围

最近记录按认证用户持久化，只保存**成功解析后的证券实体**，不保存无结果文本、错误输入或完整搜索日志。每条记录包含 `symbol / tickerCode / name / market / currency / searchedAt`。顶部搜索成功返回候选时，只记录排在首位且已通过行情验证的候选。

## 排序与去重

同一用户与同一完整 `symbol` 只有一条记录。重复搜索时更新名称、市场、币种与 `searchedAt` 并置顶；列表按 `searchedAt DESC, id DESC` 返回最多8条。每次成功记录后删除该用户第9条以后的旧记录，其他用户完全不受影响。

## 交互

搜索框没有本次结果、且存在历史时显示“最近の検索”。每条显示公司名、完整代码与市场标签；点击主体会把代码带回输入框并立即重新执行现有全市场搜索，不直接写入Watchlist。单条删除只删除当前用户该记录；“すべて削除”需要明确点击，并清除当前用户全部记录。

搜索结果仍是唯一能进入持仓、定位观察卡或加入Watchlist的位置。最近记录不缓存价格，重新搜索时取得当前价格与最新注册状态，避免陈旧价格或已持有状态误导用户。

## 隐私与错误语义

所有查询、记录、单条删除与全部清除均使用 `protectedProcedure` 和 `ctx.user.id`。前端不接受或发送任意用户ID。数据库唯一键使用 `userId + symbol`，清除操作不跨用户。数据库暂时不可用时，搜索本身仍返回结果；历史记录写入失败不会让股票搜索失败。
