# 保有銘柄一覧「未保有なら」表示不整合の監査

## 現象

保有銘柄一覧の AI シグナル列では、実際に複数口座で保有している銘柄にもかかわらず、`HOLD` の直下に「未保有でも見送る」または「仮に未保有なら買う」が表示されていた。これは保有有無の誤判定ではなく、**現在の保有行動と未保有仮説を同じ階層に並べた UI 表示の不整合**である。

## 根本原因

`Holdings.tsx` はモバイルカードで `SignalBadge` と `WouldBuyNowBadge`、デスクトップ表で `SignalBadge` と `WouldBuyNowMark` を同時に表示していた。`wouldBuyNow` は「この株を今持っていないなら新規購入するか」という独立した参考評価であり、保有状態そのものを示す値ではない。しかし一覧では説明なしに主シグナル直下へ置かれたため、「未保有」と誤読される表示になっていた。

## 修正契約

保有銘柄一覧の主表示は、実際の保有に対する `ADD / HOLD / WATCH / REDUCE / EXIT` と、その日本語ラベル「買い増し検討／継続保有／注視／一部売却検討／撤退検討」だけに統一する。これは schema v3 と旧信号の双方で `action` から決定でき、データ移行は不要である。

未保有仮説は一覧の常時表示と Tooltip の双方から削除し、保有詳細の「参考視点（未保有なら）」という折りたたみ領域だけに残す。

## 验收标准

| 场景   | 列表常显内容          | 禁止内容           |
| ------ | --------------------- | ------------------ |
| HOLD   | `HOLD 継続保有`       | 未保有でも見送る   |
| ADD    | `ADD 買い増し検討`    | 仮に未保有なら買う |
| WATCH  | `WATCH 注視`          | 未保有時も判断保留 |
| REDUCE | `REDUCE 一部売却検討` | 任何未保有副标签   |
| EXIT   | `EXIT 撤退検討`       | 任何未保有副标签   |

桌面和 390px 移动端均不得因较长日文标签产生横向溢出；正式保有列表的可见文本不得包含「未保有なら」「未保有でも」「未保有時も」。

## 生产验收记录

Railway 版本 `67bf948` 上，390px 正式保有列表的多账户トヨタ自動車行已清晰显示 `HOLD 継続保有`，原先截图中的「未保有でも見送る」已消失；页面 `scrollWidth = clientWidth = 390`，没有横向溢出。

自动化检查在 390px 与 1280px 两个视口读取全部可见 `[data-testid^="holding-signal-"]`，确认每一项均为五类实际行动或「未生成」，`forbiddenVisible=[]`、`pageForbidden=[]`。1280px 初始截图因表格内部横向可滚动，AI 列不在首屏；最终证据将主动把 AI 列滚到可视区再截图。

最终 1280px 截图已将 AI 列滚入视区，トヨタ自動車、野村ホールディングス与双日等多账户汇总行均清晰显示 `HOLD 継続保有`。390px 与 1280px 自动验收均为 `passed=true`，页面内没有「未保有でも見送る」「仮に未保有なら買う」「未保有時も判断保留」。
