# 重复观察标的生产验收记录

## 首轮截图诊断

2026-08-29 对 Railway 版本 `c06ebc3` 执行 390px 与 1280px 无写入浏览器验收。API 已正确选择真实数据：观察标的 `285A.T`、观察且持有标的 `PYPL`、仅持有标的 `7203.T`。

首轮脚本已经确认四项核心契约：重复观察查询显示 `ウォッチリスト登録済み`，重复持仓查询显示 `保有銘柄として登録済み`，重复情况下不再出现 `この銘柄を追加`，点击观察入口后 URL 变为 `/investdash/watchlist?focus={id}` 且目标卡已获得 `ring-sky-400/30` 高亮 class。

首轮自动判定失败来自等待时机而非业务代码。观察截图捕获在 Radix Dialog 退出动画和平滑滚动尚未完成时，因此仍能看到半透明退出层且目标卡尚未进入视区；持仓截图捕获在详情页 skeleton 加载阶段，因此公司名尚未渲染。验收脚本应等待打开态 dialog 消失、目标卡进入 viewport、详情 skeleton 消失并出现 ticker code 后再截图和判断。
