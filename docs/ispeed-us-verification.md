## 画面の構造

日本株と同じ 2 行構成だが、列見出しが異なる。

| 判定 | 日本株画面 | 米国株画面 |
|---|---|---|
| 列 1 の下段見出し | 銘柄コード | **ティッカー** |
| 列 3 の見出し | 平均取得価額(円) / 現在値(円) | **平均取得価額(ドル) / 現在値(ドル)** |
| 上部のラベル | （なし） | **外貨▼** |
| バッジ | 貸株中 | **貸株対象** |

この見出しで通貨を判定する。誤ると円とドルが混ざり評価額が約 150 倍ずれるため、
`brokerFormats.ts` のパターン D として明記した。

  マイクロソ… / インベスコ… / ユナイテ… / バンガー…）はすべてティッカーから補完された
- 「貸株対象」バッジはティッカーに混入しなかった
- 画面下端で切れていた NVDA / ORCL は 1 枚目では正しく除外され、2 枚目で取得できた

## 未解決: 為替レートの設定値

画面表示の「+74,746.57 ドル（+13,383,716 円）」から逆算すると、
iSPEED が使っている為替レートは **179.05 円/ドル**。

一方、本アプリの設定は **150 円/ドル**のままである。このため円換算した
米国株の評価額が実際より約 16% 低く出る。

```
米国株の評価額（150 円換算）: 約 2,900 万円
米国株の評価額（179 円換算）: 約 3,460 万円
差: 約 560 万円
```

対応方針: 設定画面から為替レートを変更できるため、ユーザーに実勢レートの確認を依頼する。
将来的には為替レートも API から自動取得するのが望ましい。
