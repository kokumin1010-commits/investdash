# 資産温度計：市場下落の客観表示

## 目的

Dashboardの最上部で、**今週・今月に資産が増えたか減ったか**と、**保有株そのものがどれだけ下落したか**を一目で確認できるようにする。長期投資家が大きな下落を感覚ではなく実測値で把握し、現金余力、追証余地、買い候補の価格帯を確認する契機にする。表示は情報提供に限定し、自動売買、即時買付、保有株の機械的な売却には連動させない。

## 最上部の表示順

検索欄の直下、キャッシュ収入と長期目標より前に「資産温度計」を置く。従来別々だった株式時価、評価損益、資産推移を同じ上部セクションへ統合し、下部の重複カードは削除する。

| 表示 | 意味 |
|---|---|
| 株式時価 | 借入で購入した分も含む保有株の現在評価額 |
| 現金性資産 | 現金宝・貨幣基金の最新残高。株式時価とは別 |
| 借入 | IBKR等の負債。純資産計算では控除 |
| 純資産 | 株式時価＋現金性資産＋通常現金−借入 |
| 評価損益 | 現在価格と取得原価の差。売却前の未実現損益 |
| 確認済みプラス現金 | 口座別スクショで確認した正の現金残高 |
| 借入・負現金 | IBKR証拠金口座等の負の現金残高 |

## 期間指標の分離

前日・7日・30日の各カードでは、主数値の種類を明記する。保有構成が同じ期間の価格差を計算できる場合は**保有株値動き**を主数値にする。構成変更または履歴不足で株式値動きを確定できない場合は、実在する純資産履歴があれば**純資産評価変動**を主数値にする。純資産差には株価、為替、入出金、現金性資産、借入が含まれるため、市場下落判定には使わない。

保有株値動きは同一構成のスナップショットに限り、株式評価額の差から取得原価差を除いた値を用いる。期間中に銘柄数が変わった場合は「構成変更」と表示し、増減を相場変動に見せない。7日または30日の対象期間に届かない履歴は「n日分のみ」と表示し、7日・30日下落率として採用しない。欠損値を0%で補完しない。

## 固定判定基準

判定は利用できる保有株値動きのうち、最も厳しい期間を採用する。閾値は画面にも表示し、将来変更する場合はコード、テスト、表示説明を同時に更新する。

| 状態 | 前日 | 7日 | 30日 |
|---|---:|---:|---:|
| 弱含み | −1.5%以下 | −3.0%以下 | −5.0%以下 |
| 調整局面 | −3.0%以下 | −7.0%以下 | −10.0%以下 |
| 大幅下落 | −5.0%以下 | −10.0%以下 | −15.0%以下 |

「通常範囲」は利用できる実測期間がすべて弱含み基準より上にある場合に表示する。利用できる期間がない場合は「判定待ち」とし、急落がないとは断定しない。

## 行動ガイダンス

弱含みでは価格帯とAction Queueを確認する。調整局面では翌月入金、確認済み現金、IBKR追証余地を確認する。大幅下落では流動性と追証余地を優先し、一括投入せず既定の分割条件を確認する。これらは**確認項目**であり、注文数量や売買判断を自動生成するトリガーではない。

## 検証

純粋判定関数は通常、弱含み、調整、大幅下落、履歴なし、複数期間の最悪値選択を回帰テストする。Dashboardテストは上部配置、前日・7日・30日、保有株値動きと純資産評価変動のラベル、現金余力、重複カード削除を確認する。全体回帰では163ファイル・1,276テスト、TypeScript検査、production buildを通過した。
