# 净资产前日比较历史回退

正式环境在2026-09-16已有20个`portfolioSnapshots`真实日次点，覆盖2026-08-25至2026-09-16；此前新建的`dailyCashFlowSnapshots`只有当日数据，因此页面首日显示前日／7日／30日未取得。

系统现在先按用户读取两套真实历史。`dailyCashFlowSnapshots`保存净资产与现金流预测完整口径，同一日期优先；该表不足时，用既有`portfolioSnapshots.netAssets`补足净资产历史。两者都只读取实际保存值，不插值、不用当前价格倒推历史。

前日、7日和30日分别寻找目标日期当日或之前最近的有效快照。周末及休场日因此会回退到最近交易／记录日，并在7日、30日和前日详情中显示实际基准日。同一JST日期如有多次旧记录，只使用最后一次；新日次表继续按用户＋日期幂等更新。

现金流预测年额的前日比只使用带预测字段的`dailyCashFlowSnapshots`，不会把旧净资产快照缺失的预测值补成0。
