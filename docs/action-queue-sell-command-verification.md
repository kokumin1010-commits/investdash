# Action Queue 長期売却・資金再配置アップグレード検証

**検証日:** 2026-09-05 JST  
**Railway commit:** `ed10960`  
**正式入口:** [SalesDash InvestDash Action Queue][1]

本アップグレードは、長期保有者が「売るかどうか」だけでなく、売却前後の損益と売却代金の使い道まで同じ画面で確認できるようにするものである。注文・送金・見送り操作は自動実行しない。

| 検証項目 | 正式環境の結果 |
|---|---|
| 方向フィルター | 対応中22件を「買入 0／売出 8／要確認 14」に切替可能 |
| 100株のみの `6920.T` | `REDUCE` を100株全売却へ変換せず、`REVIEW`、提案0株、実行後100株として表示 |
| 長期売却理由 | 「1単元のみのため、継続保有か EXIT かを改めて確認」と明示 |
| 売却損益 | 現在含み損益、概算売却代金、概算実現損益、売却後評価額、残存含み損益を実データから返却 |
| 資金用途 | IBKR が `CAUTION` のため、正式売却サンプルは売却代金を借入返済へ最優先。用途合計は売却代金と一致 |
| 見送り理由 | 「任意」と表示し、未入力の「理由なしで見送る」ボタンが有効。検証では送信していない |
| 390px | 横スクロールなし（`scrollWidth = clientWidth = 390`）。100株カード、数量提案なし、折り畳み理由を確認 |
| 1280px | 横スクロールなし（`scrollWidth = clientWidth = 1265`）。方向フィルターとカード情報が同一画面で判読可能 |

損益は現在価格と平均取得単価による円換算概算であり、税金、手数料、実際の約定価格、今後の為替変動を含まない。取得原価が信頼できない場合は損益を推測せず「算出不可」とする。資金再配置は既存の月度ランキング、銘柄上限、業種上限、現金限定、IBKR停止条件を再利用し、売却銘柄の即時買い直しを除外する。
