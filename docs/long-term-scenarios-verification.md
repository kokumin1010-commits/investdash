# 長期目標・追加入金と3情景の正式検証

検証基準日は **2026-09-07 JST**。SalesDash 正式入口 `/investdash/` を既存の1010認証で読み取り、保有・注文・アクション待ちを変更しない無書き込み UI 検証を行った。機能 commit は `82c267e`、追加 migration は `0035_past_brood.sql` で、`userSettings` に可空の年間追加入金と3情景年率だけを追加している。

正式設定は目標純資産 **¥100,000,000,000**、目標日 **2030-12-31**。年間追加入金、年間配当目標、年間利息目標、年間純キャッシュ収入目標は利用者から金額指定がないため null のままにし、追加入金は画面上で「未設定（0円で試算）」と明示した。情景年率は編集可能な名目仮定として保守4%、基準8%、楽観12%を保存した。予測や売買指示には利用しない。

| 項目 | 正式表示 |
|---|---:|
| 現在純資産 | 約7.31億円 |
| 年間配当（税引前） | ¥22,254,225 |
| 年間利息見込み | ¥3,195,330 |
| 借入年間利息 | -¥3,899,093 |
| 年間純キャッシュ収入 | ¥21,550,463 |
| 保守4%の2030年末試算 | 約8.66億円（目標0.87%） |
| 基準8%の2030年末試算 | 約10.2億円（目標1.02%） |
| 楽観12%の2030年末試算 | 約11.94億円（目標1.19%） |

各情景は、年間入金額を12等分して毎月末に投入する前提の月次複利で計算し、**現在純資産・追加入金元本・投資増減寄与**を分離している。0円入金の正式状態では追加入金元本が0億円となり、3情景すべて「未達試算」と表示された。これは目標の難易度を透明化するためで、達成可能性の予測ではない。

390px では長期目標カードが1列で読みやすく、ヘッダー、進捗、必要年率、収入と3情景が縦に続く。1280px では収入4項目と3情景が横並びになり、基準情景だけを淡い緑で強調している。自動検証では mobile `scrollWidth=clientWidth=390`、desktop `scrollWidth=clientWidth=1265` で横方向の溢れはなかった。編集画面には目標1,000億円、2030-12-31、空の入金/収入目標、4.00/8.00/12.00が正しく再表示された。
