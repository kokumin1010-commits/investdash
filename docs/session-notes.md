ユーザーからの重要な進め方の指示: **一度に複数の機能を進めず、一つずつ対応する**。他プラットフォーム（iSPEED、富途）の画面は後から提供される予定。

## Railway 移行時に対応が必要な箇所

移行を実施する際、Manus 固有の機能に依存している以下を差し替える必要がある。

| 依存 | 現在 | 移行後に必要なもの |
|---|---|---|
| LLM（OCR・ニュース分析） | `BUILT_IN_FORGE_API_URL` 経由の内蔵 LLM（gemini-3.1-pro-preview） | Google Gemini または OpenAI の API キーを自前で契約 |
| ファイル保存 | Manus の S3（`server/storage.ts`） | Cloudflare R2 等の外部 S3 |
| データベース | Manus 管理の MySQL | Railway の MySQL＋データ移行 |
| 定期実行 | Manus Heartbeat（3 ジョブ登録済み） | Railway Cron |
| 認証 | パスコード方式（Manus 非依存） | 変更不要 |

LLM 呼び出しは `server/_core/llm.ts` の `invokeLLM` に集約されているため、差し替え箇所は限定的である。OCR は `server/services/ocr.ts`、ニュース分析は `server/services/analysis.ts` から呼ばれている。

## 技術的な注意点（再発防止）

| 事象 | 原因と対処 |
|---|---|
| 株価取得が 400 エラー | Data API のクエリ値に真偽値を渡していた。文字列 `"true"` に修正 |
| 取込が 500 エラー | INSERT の戻り値から ID を取り出せず NaN になっていた。`extractInsertId` で戻り値の形（単体 / 配列 / bigint / 文字列）を吸収 |
| iOS Safari で「The string did not match the expected pattern」 | `FileReader.readAsDataURL` が TypeError を投げる。Blob URL + canvas 経由の JPEG 変換に変更 |
| 解錠後にスピナーが回り続ける | `utils.invalidate()` の完了を待っていた。待たずに進める形に変更し 30 秒のタイムアウトも追加 |
| LLM が 412 エラー | AI の利用枠上限。時間経過で復活する。緊急時は画面から読み取った値を直接投入する（`scripts/seed-sheet3.mjs` が例） |

開発時のスクリーンショット検証では、ロック画面を通過するために `?devToken=<token>` を付与できる（本番では無効）。トークンは `auth.unlock` で取得する。

## 証券プラットフォーム別の管理（2026-08-15 実装）

ユーザー要望「どの銘柄がどのプラットフォームか、ぱっと見て分かるように」に対し、
`holdings.broker` に enum（`moomoo_jp` / `rakuten_ispeed` / `futu` / `other`）を追加し、
各社ブランドカラーの色付きバッジで表示する形で実装した。既存 27 銘柄は moomoo 日本版として移行済み。
実装の詳細は `docs/broker-tracking.md` を参照。
