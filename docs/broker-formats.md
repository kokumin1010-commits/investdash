# 証券会社アプリのスクリーンショット対応状況

## moomoo 日本版（検証済み）

`server/services/brokerFormats.ts` の `moomoo_jp` として定義。

### 画面構成

| 位置 | 内容 |
|---|---|
| 上部 | 「純資産 · JPY」の直下に総額。その下に「預り金」「出金余力」「現金買付余力」が横 3 列 |
| 一覧の列 1 | 銘柄名（上段）／証券コード＋口座区分タグ（下段） |
| 一覧の列 2 | 評価額（上段）／保有数量（下段） |
| 一覧の列 3 | 評価損益の金額（上段）／損益率 %（下段） |
| 一覧の列 4 | 現在値（上段）／取得単価（下段） |

### 既知の癖

- 4 列目の取得単価が画面幅の制約で右端が切れる（`3,390.0(` のような表示になる）。
  そのため取得単価は `（評価額 − 評価損益）÷ 数量` で逆算している。
- 銘柄名が長い場合は `オリエンタル…` のように省略される。証券コードから正式名称を補完する。
- 含み損は緑色で表示される（日本の証券アプリの慣習と逆なので色では判断しない）。

### 検証結果（2026-08-15）

実際の画面（8 銘柄）で検証。レイアウト定義を渡した場合の結果:

| 項目 | 結果 |
|---|---|
| 銘柄の抽出 | 8 / 8 件 |
| 整合性チェック | 16 項目すべて誤差 0.00% |
| 純資産・預り金 | 正しく抽出 |
| 証券会社の判定 | `moomoo` と正しく認識 |
| 所要時間 | 約 53 秒 |

検証コマンド:

```
node scripts/verify-ocr.mjs --format moomoo_jp path/to/screenshot.png
```
