# AI シグナルにバフェット式の判断軸を入れる（検討）

作成日: 2026/8/19

## ユーザーが示した考え方（Intel の例）

外部 AI との会話のスクリーンショットで示された論点。

1. **取得単価は判断材料ではない。** $20 で買ったか $80 で買ったかは今日の判断に無関係。
   問うべきは「今この株を持っていなくて現金があったら、$103 で買うか？」
2. **「5 倍になったから売る」「原価を回収したから売る」は理由にならない。**
   Coca-Cola は何倍になっても売っていない。内在価値が複利で増え続けるなら
   売る方が誤り。
3. **売る理由は 1 つ。「価格の上昇速度が内在価値の上昇速度を超えた」とき。**
   （1999 年の株主への手紙の資本配置の論点）
4. **企業の型を見る。** 強い堀 → 追加資本がほとんど不要 → FCF が増える →
   利益を再投資できる → 10 年後さらに強い。Intel はこの型に合わない
   （工場が資本を食う・Foundry は転換途上・技術優位が確定的でない・
   TSMC / AMD / NVIDIA との競争）。
5. **時価総額に見合う利益を将来出せるかを問う。** 「倒産するか」ではなく
   「5,273 億ドル（あるいは 1 兆ドル）に見合う利益を出せるか」。

## 現在のシグナル判定（server/services/analysis.ts）の状況

### 既にできていること

- 「含み損の大きさそれ自体を売却理由にしてはならない。逆に含み益の大きさを
  買い増し理由にしてもならない」と明記されている（原則 1）。これは上記 1・2 と一致する。
- 投資カードのエグジット条件を最優先で確認する（原則 2）。
- 構成比 25% 超で集中リスクに言及（原則 5）。

### 欠けていること

| 欠けている観点 | 現状 | 影響 |
|---|---|---|
| **今から買うか（再取得の問い）** | 渡していない | 「持ち続ける」と「今から買う」を区別できず、HOLD の意味が曖昧 |
| **価格 vs 内在価値の伸びの比較** | 価格の騰落率（1m / 3m）は渡すが、利益や FCF の伸びは渡していない | 「上がったから割高」という価格だけの判断になる |
| **企業の型（堀・資本効率）** | セクター・業種名のみ | 資本を食う企業と食わない企業を区別できない |
| **時価総額に見合うか** | 時価総額を渡していない | 「5,273 億ドルに見合う利益を出せるか」を問えない |
| **断定を避ける指示** | 「買うべき」を禁止している（原則の末尾） | 相談 AI は断定させる方針に変えたのに、シグナルだけ曖昧なまま |

## 実装方針

### 1. 財務指標を取得して渡す

**実測の結果、財務諸表の数値は 4 市場すべてで取得できないことが判明した。**

#### 実測（2026/8/19・8 銘柄 × 4 市場）

| API | 返るもの | 財務指標 |
|---|---|---|
| `get_stock_profile` | `summaryProfile` のみ（セクター・業種・事業概要・従業員数） | **なし**。`summaryDetail` / `financialData` / `defaultKeyStatistics` はどの市場でも返らない |
| `get_stock_insights` | 米国株のみ `instrumentInfo` / `companySnapshot` / `recommendation` / `events` | 数値の財務指標はない。`valuation` は Trading Central の定性評価（Undervalued / Overvalued と割引率）のみ |
| `get_stock_holders` | `insiderHolders`（内部者の売買） | **なし** |
| `get_stock_chart` | 価格・出来高・52週高安 | **なし**。ただし月足 5 年（61 本）が全市場で取得できる |
| `get_stock_sec_filing` | SEC 提出書類の一覧（米国株のみ） | 本文の数値は含まない |

つまり **時価総額・営業利益率・ROE・FCF・PER はどの API からも数値として得られない。**
日本株・香港株・SG 株では `get_stock_insights` すら `symbol / upsell / sigDevs` の 3 キーしか返らない。

#### 取得できたもの（全市場で共通）

- **月足 5 年の株価**（61 本）: トヨタ +51.1%、リンク・リート -40.4%、
  CapitaLand -19.0%、Intel +81.5%
- 52 週高安・現在値・出来高
- セクター・業種・事業概要（英語の長文）
- 米国株のみ: Trading Central の割高/割安評価、企業スナップショット
  （革新性・採用・持続性のスコア）、決算イベント

#### 方針の変更

財務諸表を機械的に取れないため、**LLM が持つ知識を使う**。ただし数値を
捏造させないための制約を課す:

1. **数値は「概算」と明示させ、判断の根拠は定性的な記述に置く。**
   「営業利益率 23.4%」と断定させず「利益率は高い水準（概ね 20% 台）」とする。
2. **事業概要（Yahoo から取得済み・全市場で取得可能）を渡し、そこから
   企業の型を判定させる。** 工場や設備に大きな資本を必要とするか、
   ブランドや規約収入で稼ぐかは事業内容から判断できる。
3. **株価の伸びは実データを渡す。** 月足 5 年から 1 年・3 年・5 年の
   騰落率を計算して渡す。これは正確な数値。
4. **「株価はこれだけ伸びたが、企業の中身は同じ速さで伸びたか」を
   LLM に問う形にする。** 数値の比較ではなく、AI の知識と事業内容から
   判断させ、確信が持てない場合は「判断できない」と言わせる。

### 2. 「今から買うか」を明示的に問う

プロンプトに次の問いを入れる:

> この銘柄を保有していないと仮定し、同額の現金があるとき、現在値で買うか。
> 買わないなら、なぜ持ち続けるのか。

これに答えられない HOLD は実質的に「取得単価に引きずられた保有」なので、
その旨を rationale に書かせる。

### 3. 価格の伸びと中身の伸びを並べる

「株価は 1 年で +45%、営業利益は +12%」のように並べれば、
価格が中身より速く伸びたかが分かる。これがバフェットの売却基準そのもの。

### 4. 企業の型を判定させる

資本効率と利益率の推移から「追加資本をあまり必要とせず利益を伸ばせる型か」を
判定させる。Intel のような資本集約型は、同じ成長率でも必要な投資が違う。

### 5. 断定を許す

相談 AI と揃える。ただしシグナルは 5 段階（ADD/HOLD/WATCH/REDUCE/EXIT）が
既に結論なので、rationale で「なぜその結論か」を言い切らせる。
