## 重要な前提

- **平均価格・現在値は現地通貨**（USD / JPY / SGD）
- **時価評価額は SGD 換算**（基軸通貨が SGD のため）
- したがって取り込むのは「ポジション数量」と「平均価格」のみ。評価額は計算で導く
- 数量の `K` 表記は 1000 倍（`6.90K` = 6900）。3 桁に丸められている可能性がある
- 取引所コードで通貨を判定する: `TSEJ`=JPY / `NYSE`,`NASDAQ.NMS`=USD / `SGX`=SGD
