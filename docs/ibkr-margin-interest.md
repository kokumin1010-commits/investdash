## IBKR Pro の JPY マージンローン金利（階層別）

BM = IBKR ベンチマークレート（JPY は 0.830%）

| 階層（JPY） | IBKR Pro | IBKR Lite |
|---|---|---|
| 0 〜 11,000,000 | 2.330%（BM + 1.5%） | 3.330%（BM + 2.5%） |
| 11,000,000 〜 114,000,000 | 1.830%（BM + 1.0%） | 3.330% |
| 114,000,000 〜 5,700,000,000 | 1.580%（BM + 0.75%） | 3.330% |
| 5,700,000,000 〜 23,000,000,000 | 1.330%（BM + 0.5%） | 3.330% |
| > 23,000,000,000 | 1.330%（BM + 0.5%）※ | 3.330% |

※ 最上位階層には残高に対して 1% の追加課金が適用される場合がある
（IBKR と事前に取り決めがある場合を除く）。

## 計算方法（IBKR の公式説明）

> When calculating rates, keep in mind that IBKR uses a blended rate based on the tiers below.
> For example, for a balance over USD 1,000,000, the first 100,000 is charged at the Tier I rate,
> the next 900,000 at the Tier II rate, etc.

つまり**階層ごとに区切って加重平均**する（累進課税と同じ方式）。
最上位の階層の利率が全額に適用されるわけではない。

また利息は日割りで発生し、翌月第 3 営業日に実際の利息が計上される。

## 検算（2026-08-16 時点）

借入 228,720,494 円を階層に当てると

| 階層 | 対象額 | 年率 | 年間利息 |
|---|---|---|---|
| 0 〜 1,100 万 | 11,000,000 | 2.330% | 256,300 |
| 1,100 万 〜 1 億 1,400 万 | 103,000,000 | 1.830% | 1,884,900 |
| 1 億 1,400 万 超 | 114,720,494 | 1.580% | 1,812,584 |
| **合計** | **228,720,494** | **1.729%（加重平均）** | **3,953,784** |

実績との比較: 月初来利息 −1,217 SGD ≒ 151,556 円（SGD/JPY = 124.5 で換算）。
8/1 〜 8/16 の 16 日分とすると年換算 約 3,457,000 円（借入額の 1.51%）。
階層計算の 3,953,784 円（1.729%）とは約 13% の差があるが、これは

- 月初来利息の対象日数が正確に何日か不明（営業日ベースの可能性）
- 月中に借入額が変動している可能性
- ベンチマークレートが取得時点と異なる可能性

のいずれかによるもので、桁としては整合している。
システムでは階層計算を採用し、画面で実績値と並べて確認できるようにする。

## ベンチマークレート

JPY の BM は 0.830%（2026-08-16 時点）。金利は
`階層のスプレッド + BM` で決まるため、BM が変われば全階層が同時に動く。
システムでは BM とスプレッドを分けて保持し、BM だけ更新できるようにする。
