# 收益性质分层

InvestDash将金额分为三层，任何一层都不得用另一层倒推或补齐。

| 分类 | 正式定义 | 可使用的数据 | Dashboard文案 |
| --- | --- | --- | --- |
| 纯资产评价变动 | 当前纯资产与真实历史快照的总额差，包含股票价格、汇率、现金、现金性资产、入出金及借入等影响 | `dailyCashFlowSnapshots`与`portfolioSnapshots`中真实保存的净资产 | `純資産の評価変動（未確定を含む）` |
| 股票含み損益 | 当前股票市场价值减取得成本；卖出前尚未实现 | Portfolio summary的真实`totalPnl` | `株式：含み損益（未実現）` |
| 确定现金收益 | 已付与／已计入的现金宝或货币基金利息，以及证券账户实际入金且状态为`SETTLED`的股息 | 已确认截图累计差额、记录的日次利息、实际入金记录 | `記録済みの確定キャッシュ収益` |
| 未来预测 | 按当前持股、直近配当、现金性资产余额和记录利率计算的未来运行率 | 年度配当、利息、借入利息预测字段 | `将来予想（未確定）` |

股票未卖出时的金额不是“预测收益”，而是按当前市场价格计算的**未实现评价损益**。预测收益是未来尚未发生的股息或利息运行率。现金宝已经付与／计入的利息属于已记录收益；股票股息只有实际入金后才进入确定现金收益，尚未入金的年度配当只能留在未来预测。

前日、7日和30日的纯资产差是总额变化，不代表单独的股票收益，也不代表当天确定现金收入。当前缺少按同一时点完整对齐的股票、汇率、入出金与借入逐日桥接数据，因此页面必须明确“不可按来源分解”，不得用纯资产差额反推各来源。

## 正式验收

Railway版本`7393dad`上线后，SalesDash正式页面在390px与1280px均把三类金额独立显示：股票含み损益`¥138,317,786`标为`未実現`；现金宝本年付与済み利息`¥8,223`标为`確定（記録分）`，基准日为2026-08-24；股票入金済み配当因尚无实际入金记录显示`未連携`，未补0也未使用预测值。其下方的年度配当、利息与纯现金收入继续标为`将来予想（未確定）`。

两种视口均无横向溢出、截断或卡片重叠。页面同时明确纯资产差包含股票、汇率、入出金、现金性资产及借入影响；缺少同一时点明细时不做来源分解，也不从纯资产差反推。
