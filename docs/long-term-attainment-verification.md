# 長期目標・到達時期と必要入金の正式検証

検証基準日は **2026-09-07 JST**。SalesDash 正式 Dashboard を既存の1010認証で読み取り、目標設定・保有・注文・アクション待ちを変更しない無書き込み UI 検証を行った。機能 commit は `febfb8a`。計算は現在純資産、正式設定済みの年間追加入金 **¥120,000,000（月¥10,000,000）**、保守4%／基準8%／楽観12%の名目年率仮定を使用する。

| 情景 | 2030年末試算 | 現計画での到達目安 | 2030達成に必要な月次入金 | 現計画との差 |
|---|---:|---|---:|---:|
| 保守 4% | 14.32億円（1.43%） | 2110年12月・あと84年3か月 | 17.52億円/月 | +17.42億円/月 |
| 基準 8% | 16.35億円（1.64%） | 2076年1月・あと49年4か月 | 16.09億円/月 | +15.99億円/月 |
| 楽観 12% | 18.62億円（1.86%） | 2062年5月・あと35年8か月 | 14.79億円/月 | +14.69億円/月 |

到達目安は毎月末に設定額を入金し、同じ名目年率が継続すると仮定して月ごとに残高を進め、初めて1,000億円以上になる月を表示する。最大試算期間は100年で、期間内に到達しない場合は年月を作らず「100年以内に到達しない試算」と表示する。2030年必要月次入金は同じ月次複利式を逆算し、現在計画との差を別表示する。

数値は**数学試算であり収益予測ではない**。目標達成のための借入、短期売買、買い順位変更は行わない。4%／8%／12%も編集可能な仮定で、将来リターンを保証しない。

390px 自動検証は `scrollWidth=clientWidth=390`、1280px は `scrollWidth=clientWidth=1265` で横方向の溢れがなかった。モバイルは各情景を縦に積み、デスクトップは3列で表示する。長い到達年月と億円単位の必要入金はカード内に収まり、収入目標も年間配当21億円、年間利息3億円、年間純キャッシュ収入24億円として正しく再表示された。
