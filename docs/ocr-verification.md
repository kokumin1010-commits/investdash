## 判明した課題と対処

**1. 取得単価が右端で見切れる**
iSPEED の画面では取得単価の右端が切れる（例: `3,390.0(`）。プロンプトの逆算ルール（取得単価 =（評価額 − 損益）÷ 数量）が機能し、全銘柄で正しい値を復元できた。ただし SUBARU のように割り切れない場合、`3389.315789473684` のような長い小数が出力される。画面表示値は 3,390.00 のため、**小数第 2 位で丸める後処理を追加**した。

**2. 銘柄名の省略**
`オリエンタル…` のように画面上で省略された銘柄名がそのまま抽出される。証券コード（4661）から株価 API で正式名称を取得して補完する処理が既に入っているため、実用上の問題はない。

**3. 所要時間**
1 枚あたり約 51 秒。複数枚を同時に投げる場合はさらに時間がかかるため、UI 側で処理中の進捗表示を維持する。
