# 未保有研究候補・年足 視覚確認メモ

確認日: 2026-09-12

SalesDash 正式環境で 390px と 1280px を確認した。研究候補カード、検索後の LRCX 一件表示、10年／20年／上場来の切替、調査目標線、ウォッチリスト追加操作、横方向のレイアウトは両方の画面幅で正常だった。

初回スクリーンショットでは、LRCX のカード上部が現在値・年足最新 298.22 USD、表示期間 2017〜2026、高値から 0.0% と表示される一方、線が 2024 年付近で途切れて見えた。API の年次バーを確認すると 2025 年 233.46 USD、2026 年 298.22 USD まで正しく返っており、原因は Recharts の初期描画アニメーション中にスクリーンショットを取得したことだった。

commit `26e3a40` で年足の描画アニメーションを無効化した。再確認では 390px／1280px とも 2017〜2026 の全10点が即時表示され、2026年 298.22 USD、調査目標 260 USD、summary の値が一致した。研究候補25件、初期12件表示、LRCX検索、厳格購入判断3件／今すぐ購入0件も維持され、横方向のオーバーフローはない。
