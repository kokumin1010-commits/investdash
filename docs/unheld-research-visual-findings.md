# 未保有研究候補・年足 視覚確認メモ

確認日: 2026-09-12

SalesDash 正式環境で 390px と 1280px を確認した。研究候補カード、検索後の LRCX 一件表示、10年／20年／上場来の切替、調査目標線、ウォッチリスト追加操作、横方向のレイアウトは両方の画面幅で正常だった。

ただし、LRCX のカード上部では現在値と年足最新が 298.22 USD、表示期間が 2017〜2026、高値から 0.0% と表示される一方、実際の線は 2024 年付近の約80 USDで途切れて見える。集約済み summary と Recharts に渡す bars の価格系列が一致していない可能性があるため、API の年次バーを確認し、株式分割調整の口径と描画データを修正してから正式完了とする。
