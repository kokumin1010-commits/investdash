验收基准为 **2026-09-07 JST**，正式入口为 `https://salesdash.buzzdrop.co.jp/investdash/buy-plans`，Railway 功能提交为 `56b3048`。本次仅进行认证后的只读 API 与浏览器检查，没有创建订单、修改持仓、采用计划或生成投资数据。

正式数据当前没有满足严格门槛的未持有候选，因此顶部显示“現在、条件をすべて満たす未保有候補はありません”。系统没有降低门槛或伪造“好企业”标签。以后仅当候选同时满足持仓为0、ADD价格带、无待核验、无懸念、卡片确信度至少3、资料质量为 STRONG/MODERATE、结构资料分至少18及可执行 sizing 时，才进入“未保有・品質資料と価格条件を通過”。
