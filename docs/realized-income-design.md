# 实际现金增加与未来预计分层设计

**基准日：** 2026-09-13 JST  
**范围：** Dashboard 现金宝／货币基金利息、股票股息、借入利息与长期目标现金收入。

## 现状审计

当前系统已经把现金性资产与股票持仓分开，并在净资产中加入现金性资产余额。但 Dashboard 的 `summary.interestIncomeBase` 是以当前余额和记录年化利率进行日复利推算的**未来一年预计利息**，不是已经赚到或已经到账的利息。长期目标卡又把该预测利息与按当前持仓计算的年度股息估计相加，再减去预计借入利息，标签却写作“年間純キャッシュ収入”，容易被理解为实际已经增加的现金。

股票侧的 `annualIncomeBase` 也不是券商现金账本。它以当前持股数量乘以 Yahoo 近 12 个月每股股息事件计算；月份按除权日归属，因为来源没有实际到账日。因此它只能称为**当前持仓口径的未来年度股息参考**，不能称为已到账股息。

| 数据项 | 当前真实来源 | 现有可用性 | 正确口径 |
|---|---|---|---|
| 现金宝余额 | `interestAssets.amount` | 有 | 截图／录入时点的实际余额 |
| 最新单日利息 | `interestAssets.dailyIncome` | 有，但只有最新一次 | 截止 `capturedAt` 的上一日实际计提，不是自动更新的“今日” |
| 商品开始以来累计利息 | `interestAssets.cumulativeIncome` | 有 | 截止 `capturedAt` 的实际累计；不能直接拆成当月／当年 |
| 未来年度现金宝利息 | 当前余额、年化利率与复利规则 | 有 | 预测／试算，不能计入实际收入 |
| 已到账股票股息 | 无券商现金流水表 | 无 | 必须显示未连携／未取得，不能用当前持仓反推 |
| 当前持仓年度股息 | 近 12 个月每股事件 × 当前数量 | 有 | 未来年度参考，不是已到账 |
| 借入利息 | 当前借入余额、利率与月初来利息 | 部分有 | 年度预测与月初来实际必须分开 |

## 正式数据覆盖

SalesDash 正式环境当前有 4 个富途香港现金性资产记录。总余额和未来年度利息已有结构化返回；4 条记录都带 `dailyIncome`、`cumulativeIncome` 与 `capturedAt`。但捕获时间均为 2026-08-25 UTC，不能在 2026-09-13 页面称为“今日新增”。股票股息没有实际到账账本。

## 新契约

界面先分为两层，禁止在同一数字中混合：

| 层级 | 可计入项目 | 不可计入项目 |
|---|---|---|
| 实际现金增加 | 有日期和来源的现金宝日次计提、商品累计计提、券商实际股息入金、月初来实际借入利息 | 未来年度股息、未来年度现金宝利息、未到账配当 |
| 未来预计 | 当前持仓年度股息、当前现金宝余额与利率推算利息、当前借入余额推算利息 | 不得标记为已到账或当前净资产新增 |

实际值必须携带：状态（计提／到账）、发生或捕获日期、来源、币种、FX 基准与覆盖天数。期间没有记录时返回 `null + 未取得`，不返回 0。未来预计必须显示预测口径和基准日。

## 存储策略

`interestAssets` 继续保存每个商品的最新状态。新增只追加 `interestAssetIncomeSnapshots`，每次保存现金宝记录时保留当时余额、单日利息、累计利息、币种、利率与捕获时间；同一用户／商品／捕获时间使用幂等键。历史月度／年度实际利息只汇总有记录的日期，并同时显示覆盖天数，绝不把缺失日期按利率补齐后冒充实际。

新增 `cashIncomeRecords` 保存券商实际现金流水，第一阶段支持 `DIVIDEND` 与 `INTEREST`，记录到账日、总额、税费、净额、币种、券商、symbol／商品名、来源和去重键。页面只把这张表中的股票股息称作“已到账股息”。在未录入或未导入时，正式页面显示“实际股息未连携”。

## 展示方案

Dashboard 增加独立的“现金收入：实际与预计”区块。上半区显示实际累计：最新记录日次利息、本月已记录利息及覆盖天数、年初来已到账股息、年初来实际净现金收入。下半区显示未来预计：当前持仓年度股息、现金宝年度预计利息、借入年度预计利息与未来年度净现金收入。

现金宝明细保留余额、利率与累计收益，但把“前日の利息”改为带日期的“最新记录日次利息”，避免旧截图冒充今天。长期目标的收入达成率以未来年度运行率与年度目标比较，明确标注“未来预计”；实际累计另显示年度实际进度，不进入净资产重复加总。

## 精确字段与计算契约

### 现金宝实际计提

`interestAssetIncomeSnapshots` 保存 `userId / interestAssetId / incomeDate / capturedAt / amount / dailyIncome / cumulativeIncome / annualRatePct / currency / source`。唯一键为 `userId + interestAssetId + incomeDate`，同一收益日重复保存时更新当天快照而不是重复相加。

实际日次利息只汇总 `dailyIncome != null` 的快照。月初来与年初来实际利息为对应日期范围内各商品各收益日的 `dailyIncome × snapshotFxRateJpy` 之和，同时返回 `recordedDays`、`coveredAssetDays` 与 `expectedAssetDays`。缺失日期不补值；覆盖不完整时仍可显示已记录金额，但必须标记“记录分のみ”。

商品开始以来累计利息取每个商品最新快照的 `cumulativeIncome` 后再合计，不能把多个日期的累计值相加。若任一商品缺少累计值，返回已知金额及 `PARTIAL`，而不是把缺失商品当 0。

### 股票实际到账

`cashIncomeRecords` 保存 `kind=DIVIDEND`、`status=SETTLED`、`occurredOn`、`broker`、`symbol`、`name`、`currency`、`grossAmount`、`taxAmount`、`feeAmount`、`netAmount`、`fxRateJpy`、`source`、`sourceReference` 与 `dedupeKey`。实际累计以 `netAmount × fxRateJpy` 汇总；原币金额保持不变。没有流水时为 `UNAVAILABLE`，绝不把当前持仓年度配当估计代入。

### 借入利息实际与预测

`brokerBalances.interestMtd` 仅代表当前月初来实际支払利息，因此只显示“今月实际”，不能年化后冒充年初来实际。年度借入利息继续由当前借入余额与利率推算，并放在未来预计层。只有未来新增完整历史时才计算年初来实际净现金收入；现阶段若借入存在，则 YTD 净额显示 `算定不可（借入利息履歴不足）`。

### 未来预计

未来年度股息继续使用当前持股数量乘近 12 个月每股股息，并明确 `現在保有・直近12か月実績基準`。未来现金宝利息继续用当前余额与年利率进行日复利试算。未来年度净现金收入为：

`未来年度股息 + 未来年度现金宝利息 − 未来年度借入利息`

该值只用于目标运行率，不计入“实际增加”，也不再次加到当前净资产。现金宝利息已经反映在最新现金宝余额时，净资产只使用余额，不再把累计利息重复加总。

## API契约

`portfolio.overview` 新增 `cashIncome.actual` 与 `cashIncome.forecast`。`actual` 返回最新记录日次利息、MTD/YTD已记录利息、商品开始以来累计利息、YTD已到账股息、当前月实际借入利息、覆盖状态与基准日；`forecast` 返回年度股息、年度现金宝利息、年度借入利息及年度净现金收入。

新增 `portfolio.recordDividendIncome` 供用户录入券商实际到账股息。写入前按用户隔离、金额非负、到账日、币种和 `dedupeKey` 校验；不自动生成、不从预测数反推。Dashboard不在验收中写入真实记录。

## UI契约

Dashboard 的“实际现金增加”区域固定显示：最新记录日次利息、当月已记录利息及覆盖天数、年初来已到账股息、商品开始以来累计利息和当月实际借入利息。每项显示日期、状态和来源；实际股息未连携时显示 `未連携`。

“未来年度预计”区域固定显示：当前持仓年度股息、现金宝年度预计利息、借入年度预计利息、未来年度净现金收入。长期目标收入框全部加 `未来予想` 标签，并在旁边显示本年实际记录，不再使用“当前”暗示已经到账。

移动端采用两列摘要与纵向详情，390px不得横向溢出。实际和预测使用不同色调，但不使用会把预测误读为已实现收益的绿色成功语义。

> 本模块只做收入事实与预测口径分离，不构成投资建议，也不会自动交易或自动改写券商余额。
